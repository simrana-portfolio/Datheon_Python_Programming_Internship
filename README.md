
# Datheon Python Programming Internship

## About This Project
This repository contains Python projects completed during the Datheon Python Programming Internship.

## Task 1: Hangman Game
- A terminal-based word guessing game.
- Players have 6 attempts to guess the hidden word.
- Uses Python random module.
- Tracks guessed letters and displays game results.

## Task 2: Investment Portfolio Tracker
- Allows users to enter stock symbols, buying prices, and quantities.
- Calculates total investment and current market value.
- Calculates profit or loss and percentage for each stock.
- Saves portfolio results into a CSV file.

## Technologies Used
- Python 3
- CSV Module
- Random Module
- File Handling

## Project Files
- `hangman.py` - Hangman game
- `portfolio.py` - Investment portfolio tracker
- `portfolio_summary.csv` - Portfolio results

## How to Run

Run Hangman:
```bash
python hangman.py
```

Run Portfolio Tracker:
```bash
python portfolio.py
```
